# 🤖 AI Software Development Team

An AI-powered software development team built with **CrewAI**.

This project simulates a real software development team where multiple AI agents collaborate to take a software idea from requirements to testing.

## 🚀 Features

- 👨‍💼 Product Manager AI Agent
- 🏗️ Software Architect AI Agent
- 👨‍💻 Developer AI Agent
- 🧪 QA Engineer AI Agent
- 🔄 Multi-agent collaboration
- 📚 Project Knowledge / RAG
- 🛠️ Custom AI tools
- 🔀 CrewAI Flows
- 👤 Human approval workflow
- 📊 Real-time project status dashboard
- 🔐 User registration and login
- 💾 Project history with SQLite
- 🌐 Streamlit web application
